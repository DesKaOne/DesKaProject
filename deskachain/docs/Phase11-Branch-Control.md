# Phase 11 — Branch & PR Control

## Active branch

`phase-11-indochain-wallet`

## Single-PR rule

Phase 11 uses one long-lived pull request from `phase-11-indochain-wallet` to `main`.

All Phase 11 subphases belong to this branch and PR:

- 11.1 Wallet Core
- 11.2 Wallet Transactions
- 11.3 Network Integration
- 11.4 IndoScan Integration
- 11.5 Wallet Security

Do not create or merge a separate pull request for an individual Phase 11 subphase.

## Merge gate

The Phase 11 PR may be merged only after all 11.1–11.5 scope, tests, integration evidence, security checks, documentation, and release-boundary requirements are complete.

Merging is the Phase 11 completion action, not a per-subphase action.
