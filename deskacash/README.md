# DesKaCash

- DesKaCash awalnya bernama DesKaWallet
- DesKaCash adalah e-Wallet seperti OVO, DANA, GoPay, ShopeePay, LinkAja, dan lain-lain.
- DesKaCash adalah e-Wallet berbasis blockchain, yang menggunakan **DesKaChain** sebagai jaringan blockchainnya.
- DesKaCash akan menggunakan API partner untuk melakukan top-up saldo, tarik tunai, dan pembayaran merchant.
