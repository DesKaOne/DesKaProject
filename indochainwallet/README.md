# IndoChainWallet

- IndoChainWallet adalah Wallet cryptocurrency berbasis blockchain, yang menggunakan **IndoChain** sebagai jaringan blockchainnya.
- IndoChainWallet tidak hanya menggunakan **IndoChain** sebagai jaringan blockchainnya, tetapi juga akan jaringan blockchain lain seperti **Bitcoin**, **Litecoin**, **Dogecoin**, **Ethereum**, dan lain-lain.
